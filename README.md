# ¿Me escuchas?

[Experiencia interactiva](https://gabrielamartinez1602.github.io/me-escuchas/)

Versión con 98 noticias ficticias en audio, cuatro voces sintéticas y fondo original de tensión progresiva. Las voces se superponen y terminan completas, hasta el corte seco al abrirse la reja: a partir de ese instante solo queda un pitido sostenido. El menú incluye volumen y reinicio.

- [Escuchar la mezcla en 35 segundos](https://gabrielamartinez1602.github.io/me-escuchas/ESCUCHAR-MEZCLA.html)
- [Revisar las 98 noticias](https://gabrielamartinez1602.github.io/me-escuchas/ESCUCHAR-AUDIOS.html)
- [Guiones](GUIONES.md)
- [Mezcla sonora](MEZCLA-SONORA.md)

Los audios están incluidos en el sitio; no se requiere síntesis de voz durante la reproducción. No hay videos.
